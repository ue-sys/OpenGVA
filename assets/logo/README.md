# The OpenGVA logo

| File | What it is |
|---|---|
| `opengva.svg` | The logo, on nothing: dark letters, for a light background. |
| `opengva-on-dark.svg` | The same with light letters, for a dark background. |
| `opengva.png`, `opengva-on-dark.png` | Those two as pictures 1510 pixels wide, for what cannot take an SVG (`rsvg-convert -w 1510 opengva.svg -o opengva.png`). |

The letters are `#212934` (`#eef1f5` on dark) and the last one is `#e32d26`.
The SVGs are traced from the project's artwork and are what everything else
is made from: the picture an image shows while it starts is one of them on
grey.

Cockpit's branding (`os/base/rootfs/usr/share/cockpit/branding/rocky`) is made
from these: `logo.png` and `logo-dark.png` are the two SVGs 450 pixels wide,
and the icons are the red letter alone.
